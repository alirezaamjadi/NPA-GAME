### فارسی 🇮🇷  
✨ **معرفی بازی:**  
این بازی یک پازل عددی هیجان‌انگیز است که باید عدد گمشده در دنباله را حدس بزنید! 🔢

- شما ۵ بار فرصت دارید عدد درست را حدس بزنید 🔍

- اگر ۵ تلاش اشتباه انجام دهید، مرحله فعلی ریست می‌شود 🔄

- در منو می‌توانید بازی را شروع کنید، ریست کنید، تم بازی را تغییر دهید 🌗، حالت تمام صفحه را فعال کنید 🔲 و یا بازی را ترک کنید ❌

## 🇬🇧 **Complete Game Instructions**  

### English  
✨ **Game Introduction:**  
This is an exciting number puzzle game where you guess the missing number in a sequence! 🔢  
Each level contains 10 unique puzzles that challenge your skills!  

🎯 **Game Rules:**  
- You have 5 attempts to guess the correct number 🔍  
- A correct guess takes you to the next puzzle 🚀  
- If you use all 5 wrong attempts, the current level resets 🔄  
- Press ESC to return to the main menu ⬅️  
- The menu lets you start the game, reset, change themes 🌗, toggle fullscreen 🔲, or exit the game ❌  

💾 **Saving:**  
The game automatically saves your progress so you can continue anytime! 💾  

🎨 **Features:**  
- Two beautiful and pleasant themes: Light and Dark 🌞🌚  
- Smooth graphics and a clean, attractive UI 🖌️
